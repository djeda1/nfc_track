# NOIR — NFC-карта

Лендинг бесконтактной NFC-карты NOIR. 3D-карта (Three.js) со светящейся антенной и гравировкой «волны касания» путешествует по странице при скролле: делится на 6 плиток, разлетается, собирается в телефоне и выезжает в интерактивное демо оплаты.

## Запуск

Сборка не нужна — откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
```

## Файлы

- `index.html` — готовая страница.
- `noir.html` — исходник страницы без обёртки `<html>/<head>/<body>` (формат для Claude Artifacts).
- `build.py` — собирает `index.html` из `noir.html`. После правок в `noir.html` запустите `python3 build.py`.

## Стек

Three.js 0.160, GSAP 3.12, Lenis 1.1 — подключаются с CDN. Шрифты Tiny5, Golos Text и JetBrains Mono — Google Fonts.
